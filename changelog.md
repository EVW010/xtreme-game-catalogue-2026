# Changelog - Xtreme Game Catalogue

In dit bestand houd ik bij wat ik tijdens mijn project heb gemaakt en aangepast.

## 1 november 2026

- De laatste onderdelen van mijn website aangepast.
- Mijn admin dashboard uitgebreid, zodat de admin alle games kan bekijken.
- Knoppen toegevoegd waarmee de admin games kan activeren en deactiveren.
- Inloggen aangepast zodat de admin gelijk naar het admin dashboard gaat.
- De gebruikersnaam toegevoegd aan de navigatie.
- Mijn Blade-bestanden korter en overzichtelijker gemaakt.
- De navigatie en pagina's verder verbeterd.

## 28 oktober 2026

- Een persoonlijke gamecollectie gemaakt.
- Gebruikers kunnen games toevoegen aan hun collectie.
- De statussen Wil spelen, Bezig en Uitgespeeld toegevoegd.
- Gebruikers kunnen de status van hun games aanpassen.
- Een reviewsysteem toegevoegd.
- Een voorwaarde gemaakt dat je minimaal 3 games moet hebben uitgespeeld voordat je een review mag plaatsen.
- Verder gewerkt aan het filteren.

## 26 oktober 2026

- Een zoekfunctie gemaakt waarmee je games kunt zoeken.
- Filteren op genre en platform toegevoegd.
- Verschillende rollen gemaakt voor gebruikers en admins.
- Beveiliging toegevoegd zodat niet iedereen overal toegang toe heeft.
- Ervoor gezorgd dat gebruikers alleen hun eigen games kunnen bewerken en verwijderen.

## 20 oktober 2026

- De database en migrations gemaakt.
- De gegevens van games en gebruikers toegevoegd aan de database.
- Games toevoegen gemaakt.
- Games bewerken gemaakt.
- Games verwijderen gemaakt.
- Controllers en Models gebruikt om met de database te werken.

## 12 oktober 2026

- De homepagina gemaakt.
- Een layout gemaakt voor mijn website.
- Blade-components toegevoegd.
- De basis van de pagina's en navigatie gemaakt.

## 7 oktober 2026

- Mijn project gestart.
- De eerste commit gemaakt op GitHub.
